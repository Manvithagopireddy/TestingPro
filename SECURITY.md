# Security policy

TestingPro is a local QA demonstration with synthetic data and demo credentials. Do not expose it to the public internet or use it to store real user data.

Report suspected vulnerabilities privately using GitHub private vulnerability reporting if enabled, or contact the repository owner through their profile. Do not include credentials or personal information in public issues.

Current scope: input validation, JWT verification, parameterized SQL and safe error responses. Dependency and history scanning, production authentication and rate limiting require further review.
